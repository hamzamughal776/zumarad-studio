SUPPORT / MAINTENANCE

Support after handover

Support is defined in writing for each project. There is no automatic free lifetime support or unlimited revisions.

Standard handover

Agreed source code, setup and deployment notes, a testing summary and a handover walkthrough where included. Any bug-reporting window is defined in the signed agreement.

Maintenance plan

A paid plan may include a defined number of hours or tasks, scoped bug fixes, dependency and security update checks, backup verification where configured and a maintenance summary.

Priority support

Priority response targets and emergency escalation are available only if agreed and priced. Response time is not the same as resolution time; resolution depends on diagnosis, access and third parties.

Exclusions and recurring costs

New features, redesigns, content entry, third-party outages, hosting, domains, paid APIs and subscriptions are excluded unless explicitly included. The client should retain ownership of essential accounts and billing wherever practical.

How to request support

Use [PROFESSIONAL_EMAIL] after replacing it with a monitored support address. Include the affected page, steps to reproduce and relevant screenshots; never send passwords, API keys or other secrets.
