Useful to know

Questions, answered.

Every project is different. These basics help set expectations before we begin.

What services does Zumarad Studio provide?+

Website development, responsive UI implementation, selected web application workflows, AI-powered prototypes and scoped maintenance. Advanced integrations are offered only after technical validation.

How is project pricing calculated?+

Pricing depends on scope, complexity, integrations, content readiness, timeline and risk. A final quote follows discovery and a written scope; third-party fees are identified separately.

How long will my project take?+

Timing depends on agreed deliverables, feedback speed, content and external services. The proposal will set milestones and assumptions rather than promise an unverified deadline.

Will the website work on mobile?+

Responsive behaviour is part of the intended delivery scope. The agreed project is tested across representative screen sizes; device-specific guarantees are not implied.

Do you provide source code and hosting?+

Source-code handover, hosting, domain setup and deployment are defined in the proposal. Hosting and domain charges are generally paid by the client directly unless otherwise agreed.

Are the projects shown here real client projects?+

The featured visuals are studio project concepts and prototypes, not claimed client engagements. Their status is shown on each project card and in its details.

Can you integrate AI APIs or payment gateways?+

Potentially, after provider, country eligibility, credentials, security, cost and technical requirements have been checked. No provider access or production integration is implied before validation.

What support is available after launch?+

Standard handover and optional paid maintenance can be agreed. Response targets, included hours, bug-reporting windows and revision limits are written into the project agreement; there is no unlimited lifetime support promise.

How many revisions are included?+

Revision rounds and acceptance criteria are defined in the proposal. Requests that change the agreed scope are estimated separately before work begins.

Will you maintain my website after launch?+

Optional maintenance can cover agreed bug fixes, update checks and defined support hours. Hosting, paid services and new features are separate unless the agreement says otherwise.
